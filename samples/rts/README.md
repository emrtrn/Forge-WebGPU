# RTS Starter

Oyun bu örnekte Forge SDK'nın kamera, girdi, navigasyon ve UI servislerini kullanır.

```powershell
npm run forge -- dev --project samples/rts
```

Kamerayı WASD ile kaydır. E tuşu, Scout'u duvarın ötesindeki hedefe gönderir.
Tekrar E tuşuna basınca Scout başlangıç noktasına döner. Dünya widget'ı
birimi izler ve uzakta solup gizlenir.
