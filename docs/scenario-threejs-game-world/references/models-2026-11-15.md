# Models the build used (2026-11-15)

Names as the Scenario catalogue showed them on 13 to 15 November 2026. This is a record of one build, for comparison. It is not a list of defaults: for each asset type run `recommend` with quality priority and `search` sorted `createdAt:desc`, read the schema, and run a shoot-out in engine when two candidates are close.

Counts on the records of build v2.7 (frozen on 2026-11-15; the later builds, up to v2.8.1, changed code only): 466 jobs through Scenario MCP, of 11 kinds, on 13 models (the ones this table names as used, the first version included; a model only tried in a comparison is not counted); 98 3D assets in the shipped game, 73 from an image and 25 from the builder (19 builds and 6 edits).

## Why this file is dated

Model names move. Between the first and the second version of this one build, one day apart, the top-ranked sound effect model changed and the image model received a successor, which build v2.7 then used. A skill that names a model in its steps sends the next agent to yesterday's choice. Use the route (capability, `recommend`, `search`, schema, shoot-out) and write your own dated table in the hand-over.
